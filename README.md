# Star Computers

Website for **Star Computers** — computer, laptop and mobile repair, networking, CCTV, web and printing in Gollapudi, Vijayawada.

**Live site:** [https://ramuram234.github.io](https://ramuram234.github.io)

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:8080](http://localhost:8080).

## Production build

```bash
npm run build
```

GitHub Pages deploys automatically from `main` via GitHub Actions.
